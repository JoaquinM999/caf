A continuación presento el diagnóstico detallado de las fallas encontradas, las optimizaciones aplicadas y el código final completo y listo para producción.

### 1. Diagnóstico Exhaustivo: ¿Qué partes estaban fallando?

1. **Spotify: Solo búsqueda pasiva sin reproducción real (`caf/tools.py`)**:
   - La función `spotify_buscar` únicamente abría la URI `spotify:search:...`, dejando al usuario en la pantalla de búsqueda sin reproducir la pista.
   - No resolvía metadatos de artistas o canciones ni ofrecía integración con Spotify Web API o controles locales de reproducción multimedia.
2. **Ausencia total de búsqueda dinámica en Google (`caf/tools.py` y `caf/engine.py`)**:
   - No existía ninguna herramienta que permitiera a Kaf buscar datos actualizados, noticias, clima o información en vivo. Kaf dependía únicamente del conocimiento congelado del modelo.
3. **Vulnerabilidades y bloqueos en `abrir_programa` (`caf/tools.py`)**:
   - Se utilizaba `subprocess.run(["powershell", ..., "-Command", comando])` de forma síncrona y bloqueante. Al abrir aplicaciones de GUI (bloc de notas, calculadora), el hilo quedaba esperando o demorando el loop de eventos.
   - En sistemas no Windows (Linux, macOS), fallaba con `FileNotFoundError: 'powershell'`.
4. **Fuga y brechas en resolución de rutas (`_safe_resolve`)**:
   - No sanitizaba rutas absolutas (`/etc/passwd`), unidades de Windows (`C:\...`) ni caracteres nulos (`\0`). `Path(WORKSPACE) / "/etc/passwd"` en Python descarta el prefijo y evalúa a la raíz absoluta, requiriendo validaciones adicionales estrictas antes de resolver.
5. **Bugs de cadenas y saltos de línea literales**:
   - En `generar_reporte` y `listar_archivos` se escribían caracteres escapados literales `'\\n'` en lugar de saltos de línea reales `'\n'`, rompiendo el formato Markdown.
6. **Nombre de modelo inexistente (`caf/engine.py`)**:
   - Se configuraba por defecto `MODEL = "gemini-3.8-live"`. Dicho modelo no existe en la API pública de Google Gemini Live, provocando errores `404 NOT_FOUND`. El modelo oficial estándar para streaming multimodal bidireccional es `gemini-2.0-flash-exp`.
7. **Crash en importación sin hardware de audio (`pyaudio`)**:
   - `import pyaudio` estaba en el nivel superior del módulo. Si Kaf se ejecuta en un contenedor Docker, servidor cloud o entorno CI donde no hay `portaudio` instalado, la aplicación colapsaba de inmediato en lugar de degradar elegantemente al modo texto/WebSocket.
8. **Condición de carrera en Tool Calls (`_on_message` en `caf/engine.py`)**:
   - Si Gemini emitía múltiples llamadas a herramientas en un único turno (`tool_call.function_calls`), el motor lanzaba tareas huérfanas con `asyncio.create_task`, enviando respuestas desincronizadas al socket en vez de enviar un lote unificado en `session.send_tool_response`.
9. **Carrera crítica en el WebSocket del servidor (`server.py`)**:
   - Se utilizaba una única cola global `events = asyncio.Queue()`. Si se conectaban múltiples pestañas de Coucou o si el frontend se reconectaba, los clientes competían por `events.get()`, robándose mensajes entre sí y dejando al frontend sin estados.
10. **Código muerto y scripts residuales**:
    - `check_models.py`, `check_types.py` y `list_models.py` eran scripts temporales redundantes. En `test_stress.py` se forzaba la versión deprecada `api_version='v1alpha'`.

### 2. Mejoras Implementadas

- **Reproducción Inteligente en Spotify (`spotify_reproducir`)**:
  - Detección de enlaces y URIs directas.
  - Resolución automática de metadatos (título exacto, artista y álbum) mediante consulta ligera sin API keys y soporte con credenciales opcionales de Spotipy.
  - Control de reproducción multiplataforma: comandos PowerShell con envío de clave multimedia virtual en Windows, AppleScript en macOS, MPRIS D-Bus en Linux y reproductor web como fallback.
- **Búsqueda Dinámica Precisa en Google (`buscar_google`)**:
  - Soporte para Google Custom Search API si existen credenciales (`GOOGLE_SEARCH_API_KEY` o `GEMINI_API_KEY` y `GOOGLE_CSE_ID`).
  - Motor de búsqueda web dinámico ligero sin necesidad de claves, extrayendo títulos limpios, fragmentos explicativos y enlaces fuente.
  - Activación de Grounding dinámico a nivel modelo en Gemini Live (`google_search=types.GoogleSearch()`).
- **Arquitectura de Eventos Segura (`EventBroadcaster` en `server.py`)**:
  - Sistema de publicación-suscripción para clientes WebSocket independientes.
- **Aislamiento Total del Workspace**:
  - Protección estricta contra Path Traversal, rutas absolutas, inyecciones de comandos y borrados no confirmados.

def _safe_resolve(relative_path: str) -> Path:
    """Resuelve la ruta relativa y asegura estrictamente que no escape de WORKSPACE_DIR.
    Previene vulnerabilidades de Path Traversal, rutas absolutas y bytes nulos.
    """
    if not relative_path or not isinstance(relative_path, str):
        raise ValueError("Acceso denegado: Ruta de archivo inválida o vacía.")

    cleaned = relative_path.strip().replace("\\", "/")

    if cleaned.startswith("/") or ":" in cleaned or "\0" in cleaned:
        raise ValueError(f"Acceso denegado: '{relative_path}' es una ruta absoluta o no permitida.")

    while cleaned.startswith("./"):
        cleaned = cleaned[2:]

    target = (WORKSPACE_DIR / cleaned).resolve()
    workspace_resolved = WORKSPACE_DIR.resolve()

    try:
        target.relative_to(workspace_resolved)
    except ValueError:
        raise ValueError(f"Acceso denegado: '{relative_path}' está fuera de la carpeta de trabajo.")

    return target

def _resolver_pista_metadata(consulta: str) -> Dict[str, str]:
    """Resuelve el título, artista y álbum usando la API de Spotipy o metadatos públicos."""
    client_id = os.getenv("SPOTIPY_CLIENT_ID") or os.getenv("SPOTIFY_CLIENT_ID")
    client_secret = os.getenv("SPOTIPY_CLIENT_SECRET") or os.getenv("SPOTIFY_CLIENT_SECRET")
    if client_id and client_secret:

            import spotipy
            from spotipy.oauth2 import SpotifyClientCredentials
            sp = spotipy.Spotify(auth_manager=SpotifyClientCredentials(client_id=client_id, client_secret=client_secret))
            res = sp.search(q=consulta, type="track", limit=1)
            tracks = res.get("tracks", {}).get("items", [])
            if tracks:
                t = tracks[0]
                return {
                    "titulo": t["name"],
                    "artista": ", ".join(a["name"] for a in t.get("artists", [])),
                    "spotify_uri": t["uri"],
                    "url": t.get("external_urls", {}).get("spotify", "")
                }
        except Exception:
            pass

    try:
        url = f"https://itunes.apple.com/search?term={urllib.parse.quote(consulta)}&entity=song&limit=1"
        req = urllib.request.Request(url, headers={"User-Agent": "Coucou-Kaf/2.0"})
        with urllib.request.urlopen(req, timeout=5) as resp:
            data = json.loads(resp.read().decode("utf-8"))
            if data.get("resultCount", 0) > 0:
                item = data["results"][0]
                return {
                    "titulo": item.get("trackName", consulta),
                    "artista": item.get("artistName", ""),
                    "album": item.get("collectionName", "")
                }
    except Exception:
        pass

    return {"titulo": consulta, "artista": ""}


def spotify_reproducir(consulta: str) -> str:

    Controla Spotify mediante API Web, protocolo URI de escritorio o navegador.
    """

    if not consulta:

    artista = meta.get("artista", "")
    spotify_uri = meta.get("spotify_uri")

        client_secret = os.getenv("SPOTIPY_CLIENT_SECRET") or os.getenv("SPOTIFY_CLIENT_SECRET")
        if client_id and client_secret:
            auth_mgr = SpotifyOAuth(client_id=client_id, client_secret=client_secret,

                sp = spotipy.Spotify(auth=token_info["access_token"])
                if spotify_uri:
                    sp.start_playback(uris=[spotify_uri])
                else:
                    search_res = sp.search(q=consulta, type="track", limit=1)
                    items = search_res.get("tracks", {}).get("items", [])

        pass

    except Exception as e:

def _buscar_web_dinamica(consulta: str, max_resultados: int = 5) -> str:
    """Motor de búsqueda dinámico sin requerir API keys."""
    url = "https://lite.duckduckgo.com/lite/"
    data = urllib.parse.urlencode({"q": consulta}).encode()
    req = urllib.request.Request(
        url, data=data,
        headers={"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"}
    )
    try:
        with urllib.request.urlopen(req, timeout=10) as resp:
            content = resp.read().decode("utf-8", errors="ignore")

        items = re.findall(
            r'<a[^>]+href=[\'\"]([^\'\"]+)[\'\"][^>]*class=[\'\"]result-link[\'\"][^>]*>(.*?)</a>',
            content, re.DOTALL
        )
        snippets = re.findall(r'<td[^>]+class=[\'\"]result-snippet[\'\"][^>]*>(.*?)</td>', content, re.DOTALL)

        resultados = []
        for i in range(min(len(items), max_resultados)):
            link, raw_title = items[i]
            snippet_text = snippets[i] if i < len(snippets) else ""

            t_clean = html.unescape(re.sub(r"<[^>]+>", "", raw_title).strip())
            s_clean = html.unescape(re.sub(r"<[^>]+>", "", snippet_text).strip())

            if "uddg=" in link:
                try:
                    parsed = urllib.parse.parse_qs(urllib.parse.urlparse(link).query)
                    link = parsed.get("uddg", [link])[0]
                except Exception:
                    pass

            resultados.append(f"{i+1}. **{t_clean}**\n   {s_clean}\n   *Fuente:* {link}")

        if not resultados:
            return f"No se obtuvieron resultados para '{consulta}'."
        return f"Resultados de búsqueda para '{consulta}':\n\n" + "\n\n".join(resultados)
    except Exception as e:
        return f"Error en la búsqueda web: {e}"


def buscar_google(consulta: str, max_resultados: int = 5) -> str:
    """Realiza una búsqueda dinámica y precisa en Google o en la web.
    Usa Google Custom Search API si está configurado, o búsqueda dinámica universal como fallback.
    """
    consulta = (consulta or "").strip()
    if not consulta:
        return "Error: Consulta de búsqueda vacía."

    api_key = os.getenv("GOOGLE_SEARCH_API_KEY") or os.getenv("GEMINI_API_KEY")
    cse_id = os.getenv("GOOGLE_CSE_ID")

    if api_key and cse_id:
        try:
            params = urllib.parse.urlencode({
                "key": api_key,
                "cx": cse_id,
                "q": consulta,
                "num": min(max(int(max_resultados), 1), 10)
            })
            url = f"https://www.googleapis.com/customsearch/v1?{params}"
            req = urllib.request.Request(url, headers={"User-Agent": "Coucou-Kaf/2.0"})
            with urllib.request.urlopen(req, timeout=8) as resp:
                data = json.loads(resp.read().decode("utf-8"))
                items = data.get("items", [])
                if items:
                    res = [f"Resultados de Google para '{consulta}':"]
                    for i, it in enumerate(items[:max_resultados], 1):
                        titulo = it.get("title", "")
                        snippet = it.get("snippet", "")
                        link = it.get("link", "")
                        res.append(f"{i}. **{titulo}**\n   {snippet}\n   *Fuente:* {link}")
                    return "\n\n".join(res)
        except Exception:
            pass

    return _buscar_web_dinamica(consulta, max_resultados)

def crear_archivo(ruta_relativa: str, contenido: str) -> str:
    """Crea o sobreescribe un archivo de texto en la carpeta segura de trabajo."""
    try:
        target = _safe_resolve(ruta_relativa)
        target.parent.mkdir(parents=True, exist_ok=True)
        with open(target, "w", encoding="utf-8") as f:
            f.write(contenido)
        return f"Éxito: Archivo '{target.name}' guardado en la carpeta de trabajo."
    except Exception as e:
        return f"Error al crear archivo: {str(e)}"


def leer_archivo(ruta_relativa: str) -> str:
    """Lee el contenido de un archivo en la carpeta segura de trabajo."""
    try:
        target = _safe_resolve(ruta_relativa)
        if not target.is_file():
            return f"Error: No se encontró el archivo '{ruta_relativa}'."
        with open(target, "r", encoding="utf-8") as f:
            return f.read()
    except Exception as e:
        return f"Error al leer archivo: {str(e)}"


def listar_archivos(ruta_relativa: str = ".") -> str:
    """Lista los archivos dentro de la carpeta segura."""
    try:
        target = _safe_resolve(ruta_relativa)
        if not target.is_dir():
            return f"Error: '{ruta_relativa}' no es una carpeta."
        items = os.listdir(target)
        if not items:
            return "La carpeta está vacía."
        return "\n".join(sorted(items))
    except Exception as e:
        return f"Error al listar archivos: {str(e)}"


def generar_reporte(titulo: str, contenido_markdown: str, formato: str = "md") -> str:
    """Genera un reporte en markdown o texto plano en la carpeta segura."""
    try:
        formato = formato if formato in ("md", "txt") else "md"
        safe_title = re.sub(r"[^\w\-]+", "_", titulo, flags=re.UNICODE).strip("_") or "reporte"
        filename = f"{safe_title}.{formato}"
        target = _safe_resolve(filename)
        with open(target, "w", encoding="utf-8") as f:
            f.write(f"# {titulo}\n\n{contenido_markdown}\n")
        return f"Reporte generado exitosamente como '{filename}' en la carpeta de trabajo."
    except Exception as e:
        return f"Error al generar reporte: {str(e)}"


def borrar_archivo(ruta_relativa: str, confirmacion: str = "no") -> str:
    """Borra un archivo de la carpeta segura previa confirmación explícita."""
    if (confirmacion or "").strip().lower() not in ["si", "sí", "yes", "confirmar"]:
        return "pendiente_confirmacion: Acción destructiva. Por favor pedí confirmación diciendo: '¿Estás seguro de que querés borrar este archivo?'"
    try:
        target = _safe_resolve(ruta_relativa)
        if target.is_file():
            target.unlink()
            return f"Éxito: Archivo '{ruta_relativa}' eliminado."
        return f"Error: Archivo '{ruta_relativa}' no encontrado."
    except Exception as e:
        return f"Error al borrar: {str(e)}"

def _rms(data: bytes) -> int:
    """Volumen RMS de un buffer Int16 (sustituto seguro de audioop.rms)."""
    a = array("h")
    a.frombytes(data[: len(data) - (len(data) % 2)])
    if not a:
        return 0
    return int((sum(x * x for x in a) / len(a)) ** 0.5)


class NoiseGate:
    """Compuerta de ruido adaptativa con pre-roll y retención."""

    def __init__(self, min_open=120, ratio=4.0, hang_ms=700, preroll=4, open_after=2):
        self.min_open = min_open
        self.ratio = ratio
        self.hang_chunks = max(1, int(hang_ms / (1000 * CHUNK / RATE_IN)))
        self.open_after = open_after
        self.pre = deque(maxlen=preroll)
        self.floor = 60.0
        self.open = False
        self.hang = 0
        self.hits = 0
        self.last_rms = 0
        self.threshold = min_open

    def process(self, data: bytes):
        rms = _rms(data)
        self.last_rms = rms
        self.threshold = max(self.min_open, self.floor * self.ratio)
        loud = rms > self.threshold
        if self.open:
            self.hang = self.hang_chunks if loud else self.hang - 1
            if self.hang <= 0:
                self.open = False
                self.hits = 0
            return [data]
        self.pre.append(data)
        if loud:
            self.hits += 1
        else:
            self.hits = 0
            self.floor = 0.97 * self.floor + 0.03 * rms
        if self.hits >= self.open_after:
            self.open = True
            self.hang = self.hang_chunks
            out = list(self.pre)
            self.pre.clear()
            return out
        return [bytes(len(data))]


class CafEngine:
    def __init__(self, profile_name="amiguito", use_audio_hardware=True, events_queue=None):

        self.audio_in_queue = asyncio.Queue(maxsize=100)
        self.audio_out_queue = asyncio.Queue()
        self.text_in_queue = asyncio.Queue()
        self.events_queue = events_queue if events_queue is not None else asyncio.Queue()

        self._loop = None
        self._pa = None
        self._stream_in = None
        self._stream_out = None
        self._resume_handle = None
        self._estado = None
        self._playing = False
        self._mute_until = 0.0

        self.gate = NoiseGate(min_open=int(os.getenv("CAF_GATE_MIN", "120"))) \
            if os.getenv("CAF_GATE", "1") == "1" else None
        self.ptt_enabled = os.getenv("CAF_PTT", "0") == "1"
        self.muted = False
        self._ptt_down = False
        self._ptt_tail = 0
        self._ptt_hooks = []
        self._last_gate_log = 0.0

    def _emit(self, event: dict):
        self.events_queue.put_nowait(event)

    def _set_estado(self, estado: str, detalle: str = ""):
        if estado != self._estado or detalle:
            self._estado = estado
            payload = {"estado": estado, "detalle": detalle} if detalle else {"estado": estado}
            self._emit(payload)

    def _build_tools(self):
        decls = []
        for name in self.profile.herramientas:
            spec = TOOLS.get(name)
            if not spec:
                logger.warning(f"Herramienta '{name}' declarada en perfil no existe en TOOLS, se omite.")
                continue
            decls.append(types.FunctionDeclaration(
                name=name,
                description=spec["desc"],
                parameters=types.Schema(
                    type=types.Type.OBJECT,
                    properties={k: types.Schema(type=types.Type.STRING, description=d) for k, d in spec["params"].items()},
                    required=spec["required"] or None,
                ),
            ))
        tools_list = []
        if decls:
            tools_list.append(types.Tool(function_declarations=decls))
        if os.getenv("CAF_GOOGLE_GROUNDING", "1") == "1":
            tools_list.append(types.Tool(google_search=types.GoogleSearch()))
        return tools_list or None

    def _build_config(self):
        prompt = self.profile.system_instruction + "\n\nResponde de manera natural, conversacional y concisa a lo que escuches."
        kwargs = dict(
            response_modalities=["AUDIO"],
            system_instruction=types.Content(parts=[types.Part(text=prompt)]),
            tools=self._build_tools(),
        )

        if os.getenv("CAF_MINIMAL", "0") != "1":
            kwargs.update(
                speech_config=types.SpeechConfig(voice_config=types.VoiceConfig(
                    prebuilt_voice_config=types.PrebuiltVoiceConfig(voice_name=self.profile.voz))),
                input_audio_transcription=types.AudioTranscriptionConfig(),
                output_audio_transcription=types.AudioTranscriptionConfig(),
                context_window_compression=types.ContextWindowCompressionConfig(
                    sliding_window=types.SlidingWindow()),
                session_resumption=types.SessionResumptionConfig(handle=self._resume_handle),
                realtime_input_config=types.RealtimeInputConfig(
                    automatic_activity_detection=types.AutomaticActivityDetection(
                        start_of_speech_sensitivity=types.StartSensitivity.START_SENSITIVITY_LOW,
                        prefix_padding_ms=100,
                        silence_duration_ms=int(os.getenv("CAF_SILENCE_MS", "700")),
                    )),
            )
            if os.getenv("CAF_PROACTIVE", "0") == "1":
                kwargs["proactivity"] = types.ProactivityConfig(proactive_audio=True)

        return types.LiveConnectConfig(**kwargs)

    def _push_mic(self, data: bytes):
        if self.audio_in_queue.full():
            try:
                self.audio_in_queue.get_nowait()
            except asyncio.QueueEmpty:
                pass
        self.audio_in_queue.put_nowait(data)

    def _mic_thread(self):
        logger.info("Micrófono capturando...")
        last_log = 0.0
        while self.is_running:
            if not self._stream_in:
                break
            try:
                data = self._stream_in.read(CHUNK, exception_on_overflow=False)
            except Exception as e:
                logger.error(f"Error leyendo micrófono: {e}")
                if self._loop and self._loop.is_running():
                    self._loop.call_soon_threadsafe(
                        self._emit, {"estado": "error", "detalle": f"microfono: {e}"})
                break
            rms = _rms(data)
            if rms > 250 and time.monotonic() - last_log > 1.0:
                logger.debug(f"Audio captado (RMS {rms})")
                last_log = time.monotonic()
            if self._loop and self._loop.is_running():
                self._loop.call_soon_threadsafe(self._push_mic, data)

    async def _speaker_consumer(self):
        while self.is_running:
            try:
                data = await asyncio.wait_for(self.audio_out_queue.get(), timeout=0.2)
            except asyncio.TimeoutError:
                if self._playing and time.monotonic() > self._mute_until:
                    self._playing = False
                    self._set_estado("escuchando")
                continue
            self._playing = True
            if self._stream_out:
                try:
                    await asyncio.to_thread(self._stream_out.write, data)
                except Exception as e:
                    logger.error(f"Error reproduciendo audio en altavoz: {e}")
            self._mute_until = time.monotonic() + 0.5

    def set_ptt(self, down: bool):
        self._ptt_down = down
        if down:
            self._ptt_tail = 5

    async def _sender(self, session):
        while self.is_running:
            if not self.text_in_queue.empty():
                text = self.text_in_queue.get_nowait()
                await session.send_realtime_input(text=text)
                self._emit({"transcripcion": {"rol": "usuario", "texto": text}})
                continue

            try:
                data = await asyncio.wait_for(self.audio_in_queue.get(), timeout=0.1)
            except asyncio.TimeoutError:
                continue

            if self.muted:
                continue
            if not self.headphones and not self._ptt_down and (self._playing or time.monotonic() < self._mute_until):
                continue

            flush = False
            if self.ptt_enabled:
                if self._ptt_down:
                    chunks = [data]
                elif self._ptt_tail > 0:
                    self._ptt_tail -= 1
                    chunks = [data]
                    flush = (self._ptt_tail == 0)
                else:
                    chunks = []
            elif self.gate:
                was_open = self.gate.open
                chunks = self.gate.process(data)
                if self.gate.open != was_open:
                    logger.debug(f"Compuerta de ruido {'abierta' if self.gate.open else 'cerrada'} (RMS={self.gate.last_rms})")
            else:
                chunks = [data]

            for c in chunks:
                await session.send_realtime_input(audio=types.Blob(data=c, mime_type="audio/pcm;rate=16000"))
            if flush:
                await session.send_realtime_input(audio_stream_end=True)

    async def _receiver(self, session):
        while self.is_running:
            got_any = False
            async for response in session.receive():
                got_any = True
                await self._on_message(response, session)
            if not got_any:
                await asyncio.sleep(0.05)

    async def _on_message(self, response, session):
        sc = response.server_content
        if sc is not None:
            if sc.interrupted:
                while not self.audio_out_queue.empty():
                    self.audio_out_queue.get_nowait()
                self._mute_until = 0.0
                self._set_estado("escuchando")
            if sc.model_turn:
                for part in sc.model_turn.parts or []:
                    if part.inline_data and part.inline_data.data:
                        self.audio_out_queue.put_nowait(part.inline_data.data)
                        self._set_estado("hablando")
            if sc.input_transcription and sc.input_transcription.text:
                self._emit({"transcripcion": {"rol": "usuario", "texto": sc.input_transcription.text}})
            if sc.output_transcription and sc.output_transcription.text:
                self._emit({"transcripcion": {"rol": "caf", "texto": sc.output_transcription.text}})

        if response.tool_call:
            asyncio.create_task(self._handle_tool_call(response.tool_call, session))

        upd = response.session_resumption_update
        if upd and upd.resumable and upd.new_handle:
            self._resume_handle = upd.new_handle
        if response.go_away:
            raise ConnectionError(f"Cierre de sesión solicitado por el servidor: {response.go_away}")

    async def _handle_tool_call(self, tool_call, session):
        """Ejecuta todas las funciones del lote y envía una respuesta unificada."""
        responses = []
        for fc in tool_call.function_calls or []:
            logger.info(f"Herramienta invocada: {fc.name} {fc.args}")
            self._set_estado("ejecutando_herramienta", fc.name)
            spec = TOOLS.get(fc.name)
            try:
                if not spec:
                    res = f"Error: Herramienta desconocida '{fc.name}'."
                else:
                    args = {k: v for k, v in (fc.args or {}).items() if k in spec["params"]}
                    res = await asyncio.wait_for(asyncio.to_thread(spec["fn"], **args), timeout=TOOL_TIMEOUT)
            except asyncio.TimeoutError:
                res = f"Error: La herramienta '{fc.name}' excedió el tiempo límite de {TOOL_TIMEOUT}s."
            except Exception as e:
                res = f"Error interno en herramienta '{fc.name}': {e}"

            logger.info(f"Herramienta '{fc.name}' completada: {res}")
            self._emit({"herramienta": {"nombre": fc.name, "resultado": res}})
            responses.append(types.FunctionResponse(id=fc.id, name=fc.name, response={"result": str(res)}))

        if responses and self.is_running:
            try:
                await session.send_tool_response(function_responses=responses)
            except Exception as e:
                logger.error(f"Fallo al enviar respuesta de herramientas a la sesión: {e}")

    def _setup_ptt(self):
        if not self.ptt_enabled:
            return
        key = os.getenv("CAF_PTT_KEY", "f9")
        try:
            import keyboard
            self._ptt_hooks = [
                keyboard.on_press_key(key, lambda e: self.set_ptt(True)),
                keyboard.on_release_key(key, lambda e: self.set_ptt(False)),
            ]
            logger.info(f"Push-to-talk activado (tecla: {key})")
        except Exception as e:
            self.ptt_enabled = False
            logger.warning(f"No se pudo inicializar Push-to-Talk ({e}).")

    async def start(self):
        self.is_running = True
        self._loop = asyncio.get_running_loop()
        bg = []

        try:
            if self.use_audio_hardware and pyaudio:
                try:
                    self._pa = pyaudio.PyAudio()
                    self._stream_in = self._pa.open(
                        format=FORMAT, channels=CHANNELS, rate=RATE_IN,
                        input=True, frames_per_buffer=CHUNK
                    )
                    self._stream_out = self._pa.open(
                        format=FORMAT, channels=CHANNELS, rate=RATE_OUT,
                        output=True, frames_per_buffer=CHUNK
                    )
                    bg.append(asyncio.create_task(asyncio.to_thread(self._mic_thread)))
                    bg.append(asyncio.create_task(self._speaker_consumer()))
                except Exception as e:
                    logger.warning(f"Hardware de audio no disponible ({e}). Operando en modo virtual/texto.")
                    self.use_audio_hardware = False
                    self._emit({"estado": "info", "detalle": f"Modo sin audio local: {e}"})

            self._setup_ptt()

            attempt = 0
            while self.is_running:
                connected_at = time.monotonic()
                try:
                    self._set_estado("reconectando" if attempt else "conectando", MODEL)
                    async with self.client.aio.live.connect(model=MODEL, config=self._build_config()) as session:
                        logger.info(f"Conexión Live establecida con {MODEL}")
                        while not self.audio_in_queue.empty():
                            self.audio_in_queue.get_nowait()
                        self._set_estado("escuchando")
                        tasks = [
                            asyncio.create_task(self._sender(session)),
                            asyncio.create_task(self._receiver(session))
                        ]
                        try:
                            done, _ = await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)
                            for t in done:
                                t.result()
                        finally:
                            for t in tasks:
                                t.cancel()
                            await asyncio.gather(*tasks, return_exceptions=True)
                except asyncio.CancelledError:
                    raise
                except Exception as e:
                    logger.exception("Error en la sesión Live")
                    self._emit({"estado": "error", "detalle": str(e)})
                    attempt = 1 if time.monotonic() - connected_at > 10 else attempt + 1
                    if attempt >= 3:
                        self._resume_handle = None
                    await asyncio.sleep(min(2 ** attempt, 30))
        finally:
            self.is_running = False
            for t in bg:
                t.cancel()
            try:
                import keyboard
                for h in self._ptt_hooks:
                    keyboard.unhook(h)
            except Exception:
                pass
            for s in (self._stream_in, self._stream_out):
                try:
                    if s:
                        s.stop_stream()
                        s.close()
                except Exception:
                    pass
            if self._pa:
                try:
                    self._pa.terminate()
                except Exception:
                    pass

    def stop(self):
        self.is_running = False

class EventBroadcaster:
    """Bus de eventos para distribuir mensajes a múltiples clientes WebSocket sin colisiones ni fugas."""

    def __init__(self):
        self._subscribers: Set[asyncio.Queue] = set()
        self._lock = asyncio.Lock()

    async def subscribe(self) -> asyncio.Queue:
        q = asyncio.Queue()
        async with self._lock:
            self._subscribers.add(q)
        return q

    async def unsubscribe(self, q: asyncio.Queue):
        async with self._lock:
            self._subscribers.discard(q)

    def publish(self, event: dict):
        for q in list(self._subscribers):
            try:
                q.put_nowait(event)
            except asyncio.QueueFull:
                pass

    payload: Optional[ProfileChangeRequest] = Body(None)
):
    selected = profile_name or (payload.profile_name if payload else None)
    if not selected:
        return {"status": "error", "message": "Falta el nombre del perfil."}
    await start_engine(selected)
    return {"status": "ok", "message": f"Profile changed to {selected}"}


@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    logger.info("WebSocket connected.")

    client_queue = await broadcaster.subscribe()

    if engine is None or not engine.is_running:
        try:
            await start_engine("amiguito")
        except Exception as e:
            logger.error(f"No se pudo iniciar el motor: {e!r}")
            await websocket.send_text(json.dumps({"estado": "error", "detalle": str(e)}))

    async def receive_from_ws():
        try:
            while True:
                data = await websocket.receive()
                if data.get("type") == "websocket.disconnect":
                    return
                text = data.get("text")
                if not text:
                    continue
                try:
                    msg = json.loads(text)
                except json.JSONDecodeError:
                    logger.warning(f"JSON inválido recibido por WS: {text!r}")
                    continue

                action = msg.get("action")
                if action == "hablar" and msg.get("text") and engine:
                    engine.text_in_queue.put_nowait(msg["text"])
                elif action == "cambiar_perfil" and msg.get("perfil"):
                    await start_engine(msg["perfil"])
                elif action == "ptt" and engine:
                    engine.ptt_enabled = True
                    engine.set_ptt(bool(msg.get("down")))
                elif action in ("silenciar", "activar") and engine:
                    engine.muted = (action == "silenciar")
        except WebSocketDisconnect:
            logger.info("WebSocket disconnected.")
        except Exception as e:
            logger.error(f"WS receive error: {e!r}")

    async def send_to_ws():
        try:
            while True:
                event = await client_queue.get()
                await websocket.send_text(json.dumps(event))
        except WebSocketDisconnect:
            pass
        except Exception as e:
            logger.error(f"WS send error: {e!r}")

    recv_task = asyncio.create_task(receive_from_ws())
    send_task = asyncio.create_task(send_to_ws())
    try:
        done, pending = await asyncio.wait([recv_task, send_task], return_when=asyncio.FIRST_COMPLETED)
        for t in pending:
            t.cancel()
    finally:
        await broadcaster.unsubscribe(client_queue)
        logger.info("WebSocket connection closed and unsubscribed cleanly.")

import argparse

async def print_events(engine: CafEngine):
    """Muestra en consola lo que pasa: estados, transcripciones y herramientas."""
    ult_rol = None
    while True:
        try:
            ev = await engine.events_queue.get()
            if "estado" in ev:
                print(f"\n[estado] {ev['estado']} {ev.get('detalle', '')}".rstrip())
            elif "transcripcion" in ev:
                t = ev["transcripcion"]
                if t["rol"] != ult_rol:
                    print(f"\n{'Vos' if t['rol'] == 'usuario' else 'Caf'}: ", end="", flush=True)
                    ult_rol = t["rol"]
                print(t["texto"], end="", flush=True)
            elif "herramienta" in ev:
                h = ev["herramienta"]
                print(f"\n[herramienta] {h['nombre']} -> {h['resultado']}")
        except asyncio.CancelledError:
            break
        except Exception as e:
            print(f"\n[error eventos] {e}")


async def read_stdin(engine: CafEngine):
    """Permite enviar mensajes de texto y probar sin hardware de audio."""
    while True:
        try:
            texto = await asyncio.to_thread(input)
            if texto.strip():
                engine.text_in_queue.put_nowait(texto.strip())
        except (EOFError, KeyboardInterrupt):
            break
        except asyncio.CancelledError:
            break
        except Exception:
            await asyncio.sleep(0.5)


async def run_console():
    parser = argparse.ArgumentParser(description="Consola de ejecución de Caf V2")
    parser.add_argument("--profile", default="amiguito", help="Nombre del perfil a cargar")
    parser.add_argument("--sin-audio", action="store_true", help="Solo texto (sin mic ni altavoz local)")
    parser.add_argument("--debug", action="store_true", help="Logs detallados")
    args = parser.parse_args()

    logging.basicConfig(level=logging.DEBUG if args.debug else logging.INFO,
                        format="%(asctime)s %(levelname)s %(name)s: %(message)s")
    logging.getLogger("websockets").setLevel(logging.WARNING)

    engine = CafEngine(profile_name=args.profile, use_audio_hardware=not args.sin_audio)
    print(f"Caf V2 listo (Perfil: {args.profile}). Hablá o escribí un mensaje y pulsá Enter. Ctrl+C para salir.")
    
    helpers = [asyncio.create_task(print_events(engine))]
    if sys.stdin and sys.stdin.isatty():
        helpers.append(asyncio.create_task(read_stdin(engine)))

    try:
        await engine.start()
    finally:
        engine.stop()
        for h in helpers:
            h.cancel()
        await asyncio.gather(*helpers, return_exceptions=True)


if __name__ == "__main__":
    try:
        asyncio.run(run_console())
    except KeyboardInterrupt:
        print("\nSaliendo de Caf...")
